What this does

eBay's API identifies your app with a header built as Basic base64(AppID:CertID). This page joins the two values and encodes them, so you get a correct value without touching a terminal. Leading and trailing whitespace is trimmed automatically, since a stray space is the most common reason eBay rejects the header.
